# Dados para publicação

A versão preparada para GitHub está em [`publico/`](publico/README.md).
Ela contém 108.008 exemplos sintéticos e 83 relatos generalizados por IA,
sem copiar as mensagens originais ou os identificadores dos contatos.

Os originais, as tabelas intermediárias, a correspondência privada das
reescritas e os modelos treinados permanecem excluídos do Git. Não use
`git add -f` para incluir essas pastas.
